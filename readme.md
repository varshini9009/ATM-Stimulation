# ATM Simulation System

## Description
A simple ATM Simulation System developed using Python. It allows users to perform basic banking operations through a menu-driven interface. The program maintains the account balance and records transaction history using Python variables and lists.

## Features
- Check current account balance.
- Deposit money into the account.
- Withdraw money from the account.
- Prevent withdrawals exceeding the available balance.
- Maintain transaction history.
- Menu-driven interface for user interaction.
- Exit the application.

## Technologies Used
- Python
- Functions
- Global Variables
- Lists
- Conditional Statements
- Loops
- User Input and Output

## How It Works
The application starts with an initial balance of Rs. 10,000. Users can select operations from the ATM menu to check their balance, deposit money, withdraw money, or view transaction history. All transactions are maintained in a Python list during program execution.

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## Note
This is a basic Python simulation. Account balance and transaction history are stored temporarily and reset when the program exits.
